# iMall 单品商城（H5 版）

一款面向「无企业级支付渠道」人群的单品下单 H5 系统。买家下单后展示**个人收款码 + 动态应付金额**，商家人工确认到账后发货，无需第三方支付平台。

## 适用场景

针对没有申请官费企业级支付渠道、又不想接入第三方支付平台、仅能使用个人收款码收款的人群——这部分人群几乎没有「可开发接入的收款权限」，本系统以「个人收款码 + 人工确认到账」的方式闭环交易。

## 功能

- 后台创建 / 编辑 / 下架商品
- 每个商品独立 H5 单页：`/p.php?slug=商品标识`
- 多规格、库存、数量选择
- 下单填写收货信息
- 下单后展示个人收款码 + 动态应付金额（长按识别扫码付）
- 后台订单列表、确认收款、填写快递单号发货
- 买家可通过手机号查询订单状态
- 短信通知（可选，螺丝帽 LuosiMao）

## 目录结构

```
/admin/         后台管理
/admin/api/     后台 API（上传/商品/订单/设置/导出）
/api/           前端 API（下单）
/assets/        CSS/JS
/uploads/       图片上传目录（需 www 用户可写）
config.php      数据库、管理员、上传配置
functions.php   公共函数
db.php          PDO 数据库封装
install.php     初始化脚本（用完删除）
```

## 部署步骤

1. **配置数据库**：编辑 `config.php`，填入你的数据库连接信息（`DB_PASS` 等），并设置 `APP_URL`。
2. 上传源码到站点目录（如宝塔的 `/www/wwwroot/你的域名/`）。
3. 访问 `http://你的域名/install.php` 初始化数据表与默认设置。
4. 进入后台（`/admin/login.php`）→ 系统设置 → 上传个人收款码。
5. 进入商品管理 → 新建商品，上传主图/详情图，填写价格与库存。
6. **安装完成后立即删除或重命名 `install.php`**，并在后台修改默认管理员密码。

## 后台地址

```
http://你的域名/admin/login.php
账号：admin
默认密码：安装时以 install.php 页面显示为准
```

> ⚠️ 部署后请立即进入「系统设置」修改默认密码。

## 安全须知

- `config.php` 含数据库密码，**请勿将你的真实生产配置提交到任何公共仓库**。
- `install.php` 仅用于首次初始化，部署后务必删除。
- 支付方式为「个人收款码 + 人工确认」，请务必人工核对到账后再点「确认收款」，谨防伪造截图。

## 后续迁移到微信小程序

1. 保留当前后端（商品、订单、设置表不变）。
2. 前端重写为小程序页面（WXML/WXSS/JS），接口可沿用 `/api/order.php`。
3. 接入微信商户支付后，将支付页逻辑由「展示个人收款码」改为调用 `wx.requestPayment`。
4. 后台增加「微信支付开关」，可按商品或全局控制支付方式。
